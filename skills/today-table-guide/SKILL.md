# 今天吃这桌（Today Table Guide）

## 触发场景
当用户表达以下任一诉求时激活本技能：
- 约朋友或单位同事在某个商圈/写字楼/地铁站附近吃饭，需要推荐 3 家靠谱真饭馆；
- 需要结合人数、总预算或人均消费、聚餐场景、忌口/口味偏好决定怎么点菜不浪费；
- 想知道某家店适合买团购套餐还是买代金券叠加单点，并测算这顿饭的总花销与饭后 AA 分账。

## 执行工作流
1. **解析硬约束**：提取聚餐地点、用餐人数、预算方式（按人均或按总预算）、聚餐场景与口味忌口，调用 `compute_dish_quota` 计算防浪费菜量配比。
2. **检索真实餐厅**：调用 `search_nearby_restaurants`（高德开放平台 Web 服务 API）拉取目标地点周边 2 公里内真实营业饭馆（含真实评分、真实人均、距离与地址），过滤非正餐档口与严重超预算项，选出 3 家不同风味的高分真店。
3. **生成一桌配菜与预算拆解**：基于 3 家店的真实人均与菜系，按人数配比生成凉菜/硬菜/时蔬/汤主食菜单与参考总价区间，并给出团购核销策略与问阿宝查实时团购指令。
4. **团购比价精算**：若用户提供在支付宝/口碑/点评看到的真实团购套餐或代金券文字，调用 `compare_group_buy` 实算份量、忌口冲突以及「团购+补菜 vs 纯单点」差价。
5. **拍板收尾**：生成微信/钉钉群约饭通知文案、`.ics` 日历提醒及支付宝群收款 AA 分账账单（支持区分喝酒与不喝酒人员分摊）。

## 合规与事实红线
- 严禁编造不存在的餐厅、地址或评分，所有餐厅基础事实必须来自高德实时查询结果。
- 严禁凭空编造未核实的实时团购套餐标价；菜品估价必须明确标注「基于门店真实人均估算，实际以门店当日菜单为准」。
