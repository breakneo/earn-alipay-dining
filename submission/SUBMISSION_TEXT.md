【作品名称】
今天吃这桌

【作品形态与创作动机】
「今天吃这桌」是一款面向支付宝「生活好帮手」赛道的轻量化餐饮聚餐决策智能体（手机与电脑自适应 Web 应用 + 标准化 Agent Skill 契约），国内直连打开即用，无需配置任何密钥。

创作动机源自每个人都会遇到、却始终没有顺手工具解决的高频麻烦：晚上约三五好友吃饭，或临时负责安排部门 8 人聚餐，选店要翻地图看距离、翻榜单看口碑、还要核对预算是否合档；好不容易选出几家备选饭馆，点菜又犯难——4 个人或 8 个人该点几道凉菜、硬菜、时蔬才不浪费？有人不吃辣、清淡少油或要包间怎么兼顾？在支付宝口碑和高德看到团购套餐，到底买团购再加两道菜划算，还是买代金券单点更省？这顿饭不含酒水算下来人均到底多少钱？

「今天吃这桌」把「按距离与预算档位挑好正餐馆 → 逐店实时呈现按人数配好的菜单 → 一键拉起支付宝查团购并精算差价 → 生成简洁约饭通知与高德导航」串成一次 30 秒搞定的丝滑闭环。

【团队/个人介绍】
独立开发者 BreakNeo（GitHub: @breakneo），长期专注 AI Agent 工具链与贴近真实日常消费场景的轻量应用研发，坚持「真数据、零废话、打开就能用」的产品原则，致力于将大模型推理与支付宝、口碑、高德本地生活生态深度结合，降低普通人在聚餐决策中的反复比对与踩坑成本。

【目标用户与核心痛点】
目标用户：城市上班族、朋友聚会组织者、部门团建与商务宴请负责选店点菜的「攒局人」。
四大核心痛点：
1. 多维约束筛选难：地图和榜单只能按单一维度排序，常常混入咖啡厅、甜品店、快餐或远低于预算档次的简餐，无法同时兼顾「距离范围 + 甄选家数 + 口碑评分 + 预算品质档位 + 聚餐场景 + 忌口」。
2. 按人数点菜易踩坑：点少了不够吃显得局促，点多了铺张浪费且超预算，还容易忽略同桌人的忌口与场景要求。
3. 团购真假划算算不清：面对多人套餐与满减代金券，用户很难快速心算「份量够不够 N 人吃、补菜后比纯单点究竟省多少」。
4. 定店通知琐碎且易尴尬：拍板后要手动整理时间、餐厅、地址与导航链接发群，直接粘贴菜单和估价又显得不够得体。

【核心功能与使用说明】
手机或电脑直接访问 https://eat.breakneo.dpdns.org 即可零配置体验（全面适配移动端竖屏、底部原生质感抽屉选单，零横向滚动条）：
1. 灵活输入与快捷试玩：顶部「快捷试玩」下拉一键填入杭州、北京、上海、成都常见聚餐场景；支持自由输入全国任意商圈/写字楼/地铁站，自选搜索范围（500米内至5公里内）、甄选餐厅家数（1 至 10 家，默认 3 家）、用餐人数、聚餐场景、按人均或按总预算（均明确标注不含酒水）与口味忌口标签。
2. 正餐源头过滤与预算品质锚定：实时调用高德开放平台中餐厅/外国餐厅类目，严格剔除咖啡厅、甜品店、奶茶、糕饼、快餐与酒店本体，并按用户目标预算 75%~105% 的品质档位智能打分（降权不到预算一半的低档简餐与严重超标店），支持一键「换一家」。
3. 逐店实时流式配菜与防浪费预算：约 2~3 秒先呈现全部真实周边饭馆卡片与横评清单，随后并发逐店生成避开忌口的具体招牌菜清单（如 4 人配 1 凉菜 + 2 硬菜 + 1 时蔬 + 1 汤主食，8 人单位聚餐自动扩容），拿到一家立即展示一家，并算出本桌参考总价（不含酒水）、折合人均与预算结余。
4. 支付宝/口碑/高德团购联动与比价精算：每张餐厅卡片均支持「去支付宝问阿宝查团购」（手机端一键拉起支付宝搜索该店团购并自动复制精准问阿宝话术）与「高德地图直达」；展开团购比价抽屉贴入支付宝/口碑团购或代金券文案，即时评估份量、忌口冲突以及「团购加菜 vs 纯单点」的真实省钱金额。
5. 一键生成简洁约饭通知：点击「就定这家 · 生成约饭通知」，输出干净得体的群通知（仅含时间、餐厅、评分、地址与高德导航链接，隐去点菜与花销），支持导出标准 .ics 手机日历提醒；底部折叠收纳可选的饭后 AA 分摊（支持喝酒与不喝酒分开算）并可一键拉起支付宝群收款。

【所使用的主要模型、工具、第三方服务与数据来源】
1. 地图与真实餐厅数据源：高德开放平台 Web 服务 API（POI 文本检索、地理编码、周边正餐检索 `050100|050200`，实时获取全国真实餐厅名称、地址、距离、口碑评分、参考人均、招牌标签与营业时间）。
2. 大语言模型：通过国家超算互联网（SCNet）OpenAI 兼容接口调用 GLM-5.3-Flash，用于单店并发点菜搭配、团购省钱策略与团购套餐比价精算推理。
3. 云端安全托管与架构：基于腾讯云 EdgeOne Pages 边缘函数与自定义域名部署（https://eat.breakneo.dpdns.org），全部第三方 API 密钥加密存于服务端环境变量，前端零密钥暴露，国内手机 4G/5G 可直连；同时开源完整代码与 Agent Skill 契约（https://github.com/breakneo/earn-alipay-dining）。
4. 合规与真实性保障：全部推荐餐厅均为高德实时检索的真实商户，绝不虚构门店或编造未核实的实时团购标价；菜单单价与本桌总价均明确标注为「不含酒水、供参考」的智能估算，实际以门店当日菜单及支付宝/口碑团购页为准。
