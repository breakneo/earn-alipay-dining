1. 团队 / 个人介绍
个人独立创作者 BreakNeo，长期关注日常生活中的高频小痛点，喜欢用轻巧顺手的智能工具替代繁琐的来回翻找与比价，让普通人打开即用、少踩坑、少纠结。

2. 创意名称 + 创意介绍
创意名称：今天吃这桌

创作动机与灵感来源：
聚餐几乎是每个人每周都会遇到的日常小事——下班约三五好友小聚、负责安排部门 8 人聚餐，或是请客户吃顿体面饭。看似简单，实际每次都很费神：打开地图看距离、翻榜单看口碑、算人均怕超预算，挑来挑去还常混进咖啡厅、甜品店或档次不符的简餐；好不容易定下几家馆子，点菜又犯难——4 个人或 8 个人该点几个硬菜、几个素菜才既体面又不浪费？同桌有人不吃辣、要清淡少油、要包间怎么照顾？看到支付宝口碑团购套餐和代金券，到底买套餐再加菜划算，还是买代金券单点更省？拍板之后，还要整理餐厅、地址与导航发到群里。

产品形态：
「今天吃这桌」是一款面向聚餐决策场景的轻量化智能体 Web 应用（全面适配手机竖屏与电脑端，点开即用），把「按距离与预算档位挑好正餐馆 → 按人数配好一桌菜 → 支付宝/口碑团购比价 → 一键生成约饭通知与导航」串成 30 秒搞定的顺手体验。

3. 目标用户及痛点
目标用户：
城市上班族、朋友聚会组织者、部门团建与商务宴请中负责选店点菜的「攒局人」。

核心痛点：
- 选店难兼顾品质与多维要求：传统地图和榜单很难同时满足「距离范围 + 甄选家数 + 口碑评分 + 预算档次 + 聚餐场景 + 口味忌口」，容易刷出一堆咖啡厅、甜品店，或明显低于预期档次的简餐。
- 按人数点菜没谱、容易点多浪费：不知道几个人配几道凉菜、硬菜、时蔬和主食最合适，还常忽略同桌忌口。
- 团购套餐真假划算难心算：面对不同团购套餐与代金券，用户很难快速判断份量够不够吃、有没有忌口雷区、叠加补菜后比纯单点到底能省多少钱。
- 定店发群琐碎且容易尴尬：拍板后需要逐条整理时间、店名、地址与导航发群，若不小心把菜单价格一并发出又显得不够得体。

4. 功能介绍
用户如何一步步使用：
- 第一步，选定聚餐要求：手机或电脑打开即可使用，支持一键选择「快捷试玩」常见城市聚餐场景，或自由输入全国任意商圈、写字楼、地铁站；自选搜索范围（500米内至5公里内）、甄选餐厅家数（1 至 10 家，默认 3 家）、用餐人数、聚餐场景（朋友小聚 / 单位聚餐 / 商务宴请 / 家庭聚餐）、预算方式（按人均或按本桌总预算，均明确标注不含酒水）以及不吃辣、清淡少油、不要海鲜、要包间等偏好忌口。
- 第二步，秒看真实周边正餐馆并逐家呈现菜单：系统先按真实地图商户筛选指定范围内的正餐饭馆，自动过滤咖啡厅、甜品店、奶茶与快餐，并优先匹配贴近目标预算档位的品质餐厅，拿到一家餐厅的配菜方案即刻展示一家，无需干等；不满意任意一家可一键「换一家」。
- 第三步，按人数配好不浪费的一整桌菜：针对每家候选餐厅，按人数和聚餐场景给出具体的凉菜、招牌硬菜、时蔬与汤品主食搭配，明确避开忌口，并汇总本桌参考总价（不含酒水）、折合人均与预算结余情况。
- 第四步，联动支付宝查团购并精算差价：每家餐厅均提供「去支付宝问阿宝查团购」（手机端可直接拉起支付宝阿宝界面并自动复制查团购提问词）与「高德地图直达」；点开团购比价框贴入支付宝/口碑团购或代金券文案，即可核算份量是否够吃、是否踩忌口雷区，以及比纯单点预计省下多少钱。
- 第五步，拍板定店一键发群：点击「就定这家 · 生成约饭通知」，自动生成干净得体的群约饭文案（仅保留时间、餐厅、评分、地址与高德导航链接，隐去点菜与花销），并支持一键导出手机日历提醒；底部还折叠收纳了可选的饭后 AA 分摊小工具（支持喝酒与不喝酒分开算，一键跳转支付宝群收款）。

作品特色与实际价值：
- 真实可用、贴近预算品质预期：全部推荐门店均来自高德地图真实周边正餐商户，按预算档位择优推荐，不编造不存在的门店或虚假团购低价（菜单单价为不含酒水的参考估算，实际以门店当日菜单与支付宝/口碑团购页为准）。
- 手机竖屏原生级顺手体验：采用统一底部抽屉选单与紧凑对比卡片，手机单手即可完成选店、看菜、查团购与发群定店，把原本 20 分钟的反复扯皮压缩到 30 秒。
