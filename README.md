# 今天吃这桌

面向 **支付宝「智能体涌现奖」2026 第一期（生活好帮手 · 吃好每顿饭）** 的聚餐决策与团购精算智能体。

输入全国任意商圈/写字楼/地铁站、人数、预算（按人均或按总预算）、聚餐场景与忌口，自动完成：

1. **高德实时选 3 家真馆子**：接入高德开放平台 Web 服务 API，实时返回周边真实营业餐厅（真实评分、真实人均、距离、地址），自动过滤奶茶小吃档口与严重超预算店铺，并支持从候补池一键「换一家」。
2. **按人数配好一桌不浪费的菜**：调用 `GLM-5.3-Flash` 按人数科学配比（凉菜/招牌硬菜/时蔬/汤主食），严格避开忌口，算出预计总价、折合人均与预算结余。
3. **团购策略与真实比价计算器**：每家店一键复制「问阿宝查该店实时团购」指令及高德直达链接；粘贴任意支付宝/口碑/点评真实团购套餐文案，AI 立刻校验份量是否够吃、有无忌口雷区，实算「团购 + 补菜 vs 纯单点」能省多少钱。
4. **拍板收尾闭环**：点击「就定这家」一键生成微信/钉钉约饭通知、导出 `.ics` 手机日历提醒，并用支付宝群收款 AA 精算器（支持区分喝酒/不喝酒分摊）完成饭后算账。

## 在线体验
- 线上地址：`https://breakneo.github.io/earn-alipay-dining/`（免登录、免配置密钥，打开即用）

## 项目结构
- `app/`：纯中文零依赖响应式前端与核心决策引擎（`engine.js`、`api.js`、`app.js`、`index.html`、`styles.css`）
- `proxy/`：Cloudflare Worker 双路由安全代理（`/poi` 代理高德 Web 服务，`/chat` 代理 SCNet `GLM-5.3-Flash`，所有 API Key 均加密存在 Cloudflare Secrets 中）
- `skills/today-table-guide/`：智能体 Skill 规范与 `tools-schema.json`
- `tests/`：Node 原生单元测试（`npm test`）
- `submission/`：参赛提报正文、16:9 封面图与真实动态交互演示视频
